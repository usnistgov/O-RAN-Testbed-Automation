# Tutorials

These tutorials provide instructions for configuring, running, and monitoring the NIST O-RAN testbed. Complete the [installation guide](../README.md#installation-guide) before starting. Run commands from the top-level directory of the repository unless a tutorial states otherwise.

## Available Tutorials

| Tutorial | Description |
|----------|-------------|
| [OCUDU Multi-Cell and Multi-UE Grafana Monitoring](OCUDU_gNB_N_UEs_Grafana_Traffic.md) | Configure multiple cells and UEs, verify connectivity, generate traffic, and view metrics in Grafana |
| [OCUDU RIC and KPM Monitoring](OCUDU_gNB_N_UEs_RIC_xApp.md) | Connect OCUDU to the O-RAN SC Near-RT RIC or FlexRIC and collect E2SM-KPM reports |

See the [base documentation](../README.md) for supported components, system requirements, and general troubleshooting.
